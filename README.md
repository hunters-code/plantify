## 🌿 Why Plantify?

In the rapidly growing world of sustainable investments, investors struggle with identifying genuine green startups, accurate valuation, and managing portfolios across multiple investment platforms. Traditional investment tools are time-consuming, often produce suboptimal results, and lack intelligence to adapt to market conditions and sustainability metrics. Plantify addresses this challenge by providing an AI-powered platform that automatically analyzes startup sustainability profiles, generates professional investment reports, and suggests optimal investment strategies. Supporting cross-platform integration, Plantify enables users to invest, manage, and optimize portfolios with confidence. Every startup is analyzed for sustainability impact before listing, giving investors the best chance of successful green investments as they navigate the competitive sustainable investing landscape.

## 🤖 AI-Powered Investment Intelligence

Plantify's core intelligence layer is powered by advanced machine learning models that analyze startup data, sustainability metrics, and market trends in real-time to generate optimal investment recommendations, risk assessments, and portfolio strategies.

## Build and Run Yourself

### Prerequisites

- [ ] Install [Node.js 18+](https://nodejs.org/) and npm package manager
- [ ] Get OpenRouter API key for AI features from [OpenRouter](https://openrouter.ai/)
- [ ] Install [DFX](https://internetcomputer.org/docs/current/developer-docs/setup/install/) (Internet Computer SDK)

Begin by opening a terminal window.

### Setup Application:

- **Clone the repository**

  ```bash
  git clone https://github.com/hunters-code/plantify.git
  cd plantify
  ```

- **Install dependencies**

  ```bash
  npm install
  ```

- **Configure environment variables**

  ```bash
  cp .env.example .env.local
  # Edit .env.local with your API keys
  ```

- **Start Internet Computer local network**

  ```bash
  dfx start --background
  ```

- **Deploy canisters (if applicable)**

  ```bash
  dfx deploy
  ```

- **Start development server**

  ```bash
  npm run dev
  ```

- **Access the application**
  - Frontend: http://localhost:3000

## 🏃‍♂️ Running Locally

### Quick Start (Frontend Development)

1. **Install Dependencies**

```bash
# Install all npm packages
npm install
```

2. **Configure Environment Variables**
   Create or update `.env.local`:

```env
# Internet Computer Protocol (ICP) Configuration
DFX_NETWORK=local
NEXT_PUBLIC_DFX_NETWORK=local

# Supabase Configuration (required for database functionality)
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

# OpenAI Configuration (for AI features)
NEXT_PUBLIC_OPENAI_API_KEY=your_openai_api_key
OPENAI_API_KEY=your_openai_api_key
```

3. **Start Development Server**

```bash
# Start the Next.js development server
npm run dev
```

4. **Access the Application**

- **Frontend**: [http://localhost:3000](http://localhost:3000)

### Development Workflow

```bash
# Install dependencies
npm install

# Start Internet Computer local network
dfx start --background

# Deploy canisters (if applicable)
dfx deploy

# Start development server with hot reload
npm run dev

# Build for production testing
npm run build

# Start production server locally
npm run start

# Lint code
npm run lint

# Type checking
npx tsc --noEmit
```

### Troubleshooting Local Setup

**Environment Variable Issues:**

```bash
# Verify environment variables are loaded
npm run dev
# Check browser console for any "undefined" API key errors
```

**Next.js Build Issues:**

```bash
# Clear Next.js cache
rm -rf .next
npm run build

# Clear node modules if needed
rm -rf node_modules package-lock.json
npm install
```

**DFX Issues:**

```bash
# Reset local replica
dfx stop
dfx start --clean --background
dfx deploy
```

- [ ] AI features work (if OpenAI API key is configured)
- [ ] Can navigate through all pages and components
- [ ] UI components render correctly
